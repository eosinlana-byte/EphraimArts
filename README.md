# EphraimArts • Whimsical Watercolor Children's Stories & Storybook Studio

A responsive portfolio showcasing 100 children's story projects across Christian Bible & faith-based stories, bedtime adventures, and fairytales.

## 🎨 Portfolio Features
- **100 Verified Projects**: 30 Multi-Page Storybooks (381 independent page scenes), 30 Storybook Cover Designs, 15 Animated Book Trailers, and 25 Comic Books & Graphic Novels.
- **Dedicated Interactive Storybook Reader**: View single pages at a time, turn pages sequentially, view thumbnail spreads, and enjoy fullscreen mode.
- **Read Aloud Voiceover**: In-browser speech synthesis for current page text with pause, resume, and stop controls.
- **Responsive & Mobile-Ready**: Smooth touch navigation, responsive grids, and clean layout across all screen sizes.
- **Zero Pricing & Clean Presentation**: Focused on ministry, storytelling, and client inquiry.

## 🚀 How to Run Locally
1. Ensure Node.js (v18+) is installed.
2. Start the local server:
   ```bash
   npm start
   ```
3. Open your browser to `http://localhost:8080`.

## 🌐 Deploy to Render (render.com)
This repository is pre-configured with `render.yaml` and `package.json` for one-click deployment:
1. Push this repository to GitHub.
2. In [render.com](https://render.com), click **New +** → **Web Service**.
3. Select this repository and click **Create Web Service**.
4. Your website will be live at `https://ephraimarts.onrender.com`!
